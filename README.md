# Academic Report Studio

### Лабораторная работа — от методички до проверенного DOCX

![Python](https://img.shields.io/badge/Python-3.10%2B-3776AB?logo=python&logoColor=white)
![DOCX](https://img.shields.io/badge/формат-DOCX-2B579A)
![Язык](https://img.shields.io/badge/язык-русский-4C1)
![Данные](https://img.shields.io/badge/персональные_данные-не_включены-success)

Навык для программных агентов, который помогает выполнить учебное задание по методическим указаниям, проверить результат и подготовить аккуратный отчёт Microsoft Word.

</div>

> Репозиторий содержит только инструкции, справочники, сценарии и обезличенные шаблоны. Шапка СПбПУ сохранена; ФИО студента, группа, преподаватель, дисциплина и готовые учебные работы не публикуются.

## Что умеет

| Задача | Результат |
|---|---|
| Разобрать методичку | Требования превращаются в проверяемые критерии |
| Выполнить лабораторную | Используются реальные команды, расчёты и тесты |
| Оформить готовый проект | В отчёт попадают только подтверждённые результаты |
| Собрать документ | Создаётся `.docx` с титульным листом, содержанием, таблицами, рисунками, формулами и приложениями |
| Проверить оформление | Выполняются структурная проверка и визуальный контроль страниц |
| Защитить личные данные | Персональные реквизиты хранятся только в локальном проекте пользователя |

## Как это работает

```text
Методичка → критерии → выполнение и анализ → доказательства → DOCX → проверка
```

Навык поддерживает два сценария:

- **выполнение и отчёт** — агент выполняет обязательные пункты работы, запускает проверки и документирует подтверждённый результат;
- **только отчёт** — агент исследует существующий проект и материалы, не приписывая работе отсутствующие результаты.

## Быстрый старт

### 1. Получить репозиторий

```bash
git clone https://github.com/<владелец>/academic-report-studio.git
cd academic-report-studio
```

Замените `<владелец>` на имя владельца учётной записи или организации.

### 2. Установить навык

Найдите каталог навыков своего агента — в документации он может называться `skills directory`, `skills path` или похожим образом.

macOS и Linux:

```bash
export AGENT_SKILLS_DIR="/абсолютный/путь/к/каталогу/skills"
mkdir -p "$AGENT_SKILLS_DIR"
cp -R skills/academic-report-studio "$AGENT_SKILLS_DIR/"
```

Windows PowerShell:

```powershell
$AgentSkillsDir = "C:\путь\к\каталогу\skills"
New-Item -ItemType Directory -Force -Path $AgentSkillsDir
Copy-Item -Recurse -Force "skills\academic-report-studio" $AgentSkillsDir
```

После установки основной файл должен находиться здесь:

```text
<каталог-навыков>/academic-report-studio/SKILL.md
```

### 3. Установить зависимости

Рекомендуется отдельное виртуальное окружение:

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r skills/academic-report-studio/requirements.txt
```

Для преобразования PDF в изображения при визуальной проверке:

```bash
python -m pip install -r skills/academic-report-studio/requirements-render.txt
```

LibreOffice устанавливается отдельно средствами операционной системы. Он должен быть доступен через `PATH` или находиться в стандартном каталоге установки.

### 4. Обновить конфигурацию агента

Перезапустите агента или выполните его команду обновления списка навыков. Убедитесь, что в списке появился `academic-report-studio`.

Файл `agents/agent.yaml` содержит нейтральные метаданные интерфейса. Если ваша платформа ожидает другое имя или расположение YAML-файла, перенесите поля `display_name`, `short_description` и `default_prompt` по её документации.

## Если агент не поддерживает навыки напрямую

1. Сохраните каталог `skills/academic-report-studio` целиком в доступном агенту рабочем пространстве.
2. Добавьте в проектные инструкции требование полностью читать `SKILL.md` перед началом работы.
3. Разрешите чтение `references/` и `assets/` относительно каталога навыка.
4. Разрешите запуск сценариев из `scripts/` в изолированном Python-окружении.
5. Запретите выдумывать реквизиты, результаты, измерения, источники и снимки экрана.

Пример проектной инструкции:

```text
Перед выполнением лабораторной работы полностью прочитай
skills/academic-report-studio/SKILL.md и следуй его требованиям.
Все связанные пути разрешай относительно каталога навыка.
```

## Примеры запросов

Выполнить работу и подготовить отчёт:

```text
Используй навык academic-report-studio. Изучи методические указания,
выполни обязательные пункты, проверь результат и создай итоговый DOCX.
```

Оформить существующий проект:

```text
Используй навык academic-report-studio. Проверь проект и приложенные
материалы, затем подготовь отчёт только по подтверждённым результатам.
```

Агент должен запросить только недостающие реквизиты и доказательства. Он не должен придумывать персональные данные, результаты запуска, измерения, ссылки или снимки экрана.

## Локальные профили и приватность

Персональные сведения храните рядом со своим учебным проектом, но не в этом репозитории:

- `.report-profile.json` — ФИО студента, группа и постоянные реквизиты;
- `.report-subjects.json` — дисциплина, ФИО и должность преподавателя.

Встроенный `assets/report-profile.default.json` содержит шапку СПбПУ и город, но поля студента и группы пусты. Файл `assets/report-subjects.default.json` также пуст.

Локальные профили, задания, датасеты, DOCX/PDF, результаты отрисовки, журналы и секреты исключены через `.gitignore`.

## Структура

```text
skills/academic-report-studio/
├── SKILL.md                 # основной рабочий процесс
├── agents/agent.yaml        # метаданные интерфейса
├── assets/                  # шапка СПбПУ и пустые персональные поля
├── references/              # правила выполнения и оформления
├── scripts/                 # сборка, проверка, отрисовка и очистка
├── requirements.txt
└── requirements-render.txt
```

## Проверка установки

```bash
python skills/academic-report-studio/scripts/build_report.py --help
python skills/academic-report-studio/scripts/validate_report.py --help
python skills/academic-report-studio/scripts/render_docx.py --help
```

Затем примените навык к небольшому синтетическому заданию. Тестовые ФИО, группа и дисциплина не должны попадать в Git.

## Системные требования

- Python 3.10 или новее;
- агент, способный читать `SKILL.md` и связанные файлы;
- право на запуск локальных Python-сценариев и создание `.docx`;
- LibreOffice для преобразования DOCX в PDF при визуальной проверке;
- одно из средств растеризации PDF из `requirements-render.txt`.

## Безопасность и академическая добросовестность

Используйте навык только для материалов, которые разрешено обрабатывать. Не публикуйте чужие отчёты, задания, персональные данные и закрытые датасеты.

Навык не фабрикует результаты, не заявляет о невыполненных экспериментах, не копирует работу другого студента и не отправляет документы в образовательные системы или внешние сервисы без явного разрешения пользователя.
