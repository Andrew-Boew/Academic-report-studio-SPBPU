# Каталог титульных листов и композиция документа

Правила тела документа заданы единым профилем `spbpu-profile.md`
(ГОСТ 7.32-2017 + tr23-26) и одинаковы для лабораторной, курсовой, ВКР
и отчёта о НИР. Этот файл описывает только титульные листы — они выбираются
полем `metadata.cover_layout` — и состав структурных элементов по виду
работы. Институт и высшая школа по умолчанию: **Институт компьютерных наук
и кибербезопасности (ИКНК)** и **Высшая школа кибербезопасности (ВШК)**
(`assets/report-profile.default.json`); значения берутся из профиля
пользователя, а не придумываются.

## Выбор макета

| `cover_layout` | Вид работы | Когда использовать |
|---|---|---|
| `lab` | Лабораторная работа | по умолчанию для `report_type: lab` |
| `course` | Курсовая работа | по умолчанию для `report_type: course` |
| `vkr_2026` | ВКР | официальная форма 2026 года |
| `vkr_tr23` | ВКР | форма Приложения А пособия tr23-26 |
| `nir` | Отчёт о НИР | форма по ГОСТ 7.32-2017 6.10 |

Тело документа от выбора не зависит: шрифт, поля, заголовки, таблицы,
формулы, содержание и приложения оформляются одинаково при любом макете.

## Макеты `lab` и `course`

Порядок сверху вниз:

1. Министерство науки и высшего образования Российской Федерации.
2. Полное название университета.
3. Институт (ИКНК).
4. Высшая школа — полужирным (ВШК).
5. `Лабораторная работа № N` или `Курсовая работа` — 14 пт, полужирный, по центру.
6. Тема в кавычках-ёлочках — 14 пт, полужирная, по центру.
7. `по дисциплине «…»` — 14 пт, по центру.
8. Блок студента: роль, статус и группа слева, сокращённое имя у правого края; ниже отдельная центрированная строка `<подпись>` — 12 пт, курсив.
9. Блок проверяющего: строка `Проверил:`, затем должность слева и сокращённое имя справа; ниже отдельная центрированная строка `<подпись>` — 12 пт, курсив.
10. Город и год — по центру у нижнего края. Номер страницы скрыт.

Не добавлять организационно-правовую форму сверх указанной, дату, оценку
и незапрошенные реквизиты.

## Макет `vkr_2026`

Официальная форма титульного листа ВКР 2026 года:

1. Министерство — полужирным, по центру.
2. `ФГАОУ ВО «Санкт-Петербургский политехнический университет Петра Великого»` — полужирным, по центру.
3. Институт (ИКНК) и Высшая школа (ВШК) — полужирными строками по центру.
4. `ВЫПУСКНАЯ КВАЛИФИКАЦИОННАЯ РАБОТА` — полужирным, по центру.
5. `на тему: «Тема»` — полужирным, по центру.
6. Левый блок строк: `Выполнил(а): студент(ка) N курса, группы …`, `Ф.И.О.: …`, `Подпись: ____`; `Научный руководитель:`, должность и степень, `Ф.И.О.: …`, `Оценка: ____`, `Подпись: ____`; `Нормоконтроль:`, `Подпись: ____`. Незаполненные значения остаются форменными прочерками.
7. `Санкт-Петербург 2026` — в нижнем колонтитуле первой страницы по центру; номер страницы скрыт.

## Макет `vkr_tr23`

Форма Приложения А пособия tr23-26:

1. Министерство; университет прописными; институт; высшая школа полужирным — по центру.
2. Блок допуска у правого края: `Работа допущена к защите`, `Директор ВШК`, линия и инициалы, `«___» ________ 20__ г.`
3. `ВЫПУСКНАЯ КВАЛИФИКАЦИОННАЯ РАБОТА` по центру; под ней 12 пт строка вида ВКР (работа бакалавра, дипломный проект, дипломная работа, магистерская диссертация).
4. Тема прописными полужирным по центру.
5. `по направлению подготовки …` и `направленность (профиль) …` — по центру при наличии данных.
6. Три колонки подписей: роль слева, `<подпись>` по центру, инициалы и фамилия справа — для студента, руководителя и консультанта по нормоконтролю.
7. Город и год внизу по центру.

## Макет `nir`

Титульный лист отчёта о НИР по ГОСТ 7.32-2017 6.10:

1. Министерство по центру.
2. Полное наименование организации прописными; сокращённое в круглых скобках на отдельной строке (`(СПбПУ)`).
3. Слева: `УДК …`, `Рег. N НИОКТР …`, `Рег. N ИКРБС …` — по наличию данных.
4. Справа: гриф `УТВЕРЖДАЮ`, должность, линия и инициалы, дата.
5. По центру: `ОТЧЕТ` / `О НАУЧНО-ИССЛЕДОВАТЕЛЬСКОЙ РАБОТЕ`.
6. Наименование отчёта прописными; вид отчёта в круглых скобках (`заключительный`, `промежуточный, этап N`).
7. `Руководитель НИР`, должность, линия и инициалы.
8. Место и год внизу по центру через пробел.

## Состав структурных элементов по виду работы

Тело одинаково; различается только набор элементов до и после него:

- лабораторная: титульный лист → СОДЕРЖАНИЕ → разделы → ВЫВОДЫ → приложения. Без реферата, задания и списка источников (если методичка прямо не требует иное — зафиксировать конфликт).
- курсовая: титульный лист → СОДЕРЖАНИЕ → разделы → ЗАКЛЮЧЕНИЕ → СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ → приложения.
- ВКР: титульный лист → (ЗАДАНИЕ — только если вшивается по требованию) → РЕФЕРАТ + ABSTRACT → ПЕРЕЧЕНЬ СОКРАЩЕНИЙ И ОБОЗНАЧЕНИЙ (при более трёх обозначениях) → СОДЕРЖАНИЕ → разделы → ЗАКЛЮЧЕНИЕ → СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ → приложения.
- отчёт о НИР: как ВКР, титульный лист по макету `nir`; состав предварительных элементов определяет текущее задание.

Блоки `abstract`, `assignment`, `abbreviations` в спеке автоматически
размещаются перед содержанием; флаг `"position": "body"` оставляет блок
в основном потоке.

## Защита от дефектов вёрстки

- Не оставлять почти пустые случайные страницы; страницы разрыва разделов
  с малым содержанием — намеренные по ГОСТ 6.2.1, но не для подразделов.
- Не оставлять заголовок, вводную ссылку или подпись отдельно от объекта.
- После материализации содержания повторно рендерить документ.
- В финальном DOCX каждая строка содержания имеет положительный,
  заранее материализованный номер страницы; значение 0 запрещено.
- Просматривать каждую итоговую страницу при масштабе 100 % до передачи DOCX.
